# 台股技術分析儀表板（繁體中文版）

本專案已完成計畫中的第零至第五階段：真實行情、法人、融資融券、價格結構、七因素證據矩陣、市場階段，以及五層同步互動圖。尚未進入第六階段。

## 安裝與啟動

需要 Python 3.12 以上版本。在專案目錄執行 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[dev]"
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702 --phase2
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702 --phase3
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702 --phase4
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702 --phase5
.\.venv\Scripts\python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

開啟終端機顯示的本機網址。按「更新市場資料」取得官方行情；切換股票或圖表區間只會讀取本機資料庫，不會重新下載。使用 Ctrl+C 停止服務。不需要 API 金鑰或付費服務。

如需重現已驗證的 Windows／Python 3.12 套件版本，可先安裝 `requirements-lock.txt`，再執行 `pip install --no-deps -e .`。

## 操作方式

- 「個股詳情」顯示股價、最新交易日、資料品質與來源。
- 五層圖表依序為開高低收 K 線與 5／20／60 日均線、成交量與 20 日均量、三大法人買賣超、融資餘額與日增減、RSI14 與 30／50／70 參考線。
- 三大法人以外資及陸資、投信、自營商分開呈現，可用圖例個別切換。融資餘額是存量，單位保持證交所原始「交易單位」。
- 可選 20、60、120 個交易日或近一年，並縮放、平移、重設座標軸及點選圖例切換曲線。
- 游標停留在圖表時顯示精確價格、成交股數與成交金額；「逐日精確資料與來源」可核對完整欄位。
- 「資料品質與限制」列出警告與歷次檢查紀錄。通過（含警告）不代表已完整核對公司行動與交易日。

MA、RSI、TWSE 等標準縮寫保留。應用程式內容使用繁體中文；Streamlit／Plotly 內建工具列的部分提示文字由套件提供。

## 設定與儲存

- `config/holdings.yaml`：預設 3702 大聯大，成本與持股張數保持空值。
- `config/settings.yaml`：資料庫與快取路徑、初次下載 15 個月份、超過 7 個日曆日的過期提醒。相對路徑以專案目錄為準。
- `config/sources.yaml`：證交所官方端點與單位。
- `data/stocks.duckdb`：依股票代號與交易日期儲存驗證後行情，另存資料品質紀錄。
- `institutional_daily`：外資及陸資、投信、自營商及三大法人合計；單位為股。
- `margin_daily`：融資與融券的買賣、償還及餘額；單位為交易單位。
- `data/cache/`：官方原始回應、SHA256 與擷取時間。正式資料與快取不納入 Git。
- `tests/fixtures/`：真實官方回應與人工核對的十日回歸資料，僅供測試使用。

後續更新從最後儲存的月份取得至今，因官方介面以月為單位提供資料。如需重新檢查較早資料的官方修訂：

```powershell
.\.venv\Scripts\python -m src.services.stock_service --ticker 3702 --full
```

官方數值變更會記錄原值與新值，原始回應亦保留。單檔股票更新採完整交易：任一月份失敗便不提交部分結果。來源暫時無資料、新上市股票歷史不足或當月尚無資料時，更新可能被阻擋；不會以假資料替代。請避免命令列與介面同時寫入 DuckDB。

第二階段首次下載最近 250 個行情交易日。官方每日介面可能暫時限流；程式會退避後重試，並以內容雜湊封存每個原始回應。再次執行會重用已驗證快取，只下載缺少日期。使用 `--phase2 --full` 可強制重新下載全部 250 日。

第三階段不需網路：它從已驗證資料計算確認型轉折、HH／HL／LH／LL、結構狀態與兩級支撐壓力。設定檔可調整左右確認日數與價位合併容差；每個 pivot 同時保存轉折日及確認日，歷史快照只會使用當時已確認的資料。

第四階段將價格結構、RSI、移動平均線、成交量、三大法人、融資與支撐壓力保存為七份獨立的結構化證據。每份證據包含狀態、標題、目前數值、觀察值、推理及來源日期；缺少必要資料時明確標示資料不足，不產生單一買賣分數。

第五階段以固定規則與優先序判定下降趨勢、初步築底、底部確認、上升趨勢、過熱、高檔修正、結構轉弱、過渡期或無法分類。每個交易日保存判定理由及引用的證據因素；階段是證據摘要，不是買賣建議。

## 計算規則

均線採完整交易日視窗。RSI14 以首 14 個每日漲跌的平均漲幅、平均跌幅起算，再依 Wilder 平滑遞推；第 15 筆才有首個 RSI，第 60 筆才有首個 MA60。全平盤 RSI 為 50、只有上漲為 100、只有下跌為 0。收盤價缺漏時重新累積 RSI 所需歷史。

20 日量比＝當日成交股數／包含當日在內的 20 日平均成交股數。分母為零時保持缺值。指標先以全部歷史計算，再裁切顯示區間；近一年以最新儲存交易日往前推一個日曆年。

法人分別計算 3／5／10／20 日淨買賣超合計。融資計算 1／5／10／20 日餘額增減及 20 日增減率；融資餘額不被解讀為持有成本分布。每個來源日都驗證法人分項合計等於官方總計，並核對融資與融券的前日餘額、買賣及償還公式。

## 資料品質與來源限制

官方來源為 `https://www.twse.com.tw/exchangeReport/STOCK_DAY`。成交股數單位為「股」，不是「張」；成交金額為新臺幣。民國年份加 1911 轉為西元。

- 目前只支援證交所上市股票，尚未接入櫃買中心。法人來源為官方 T86；融資融券來源為官方 MI_MARGN。
- 使用未還原權息價格。官方 X／** 標記或收盤變動超過 11% 會提醒核對；股利、分割、減資與增資尚未完整整合。
- 尚無官方交易日曆，因此交易日缺漏完整性標示為未驗證；不會自行補值或插入休市日。
- 目前為單一官方來源，不能獨立比對跨來源差異；已下載月份的官方修訂會留存紀錄。
- 空資料、混合股票、重複／未排序／未來日期、無效價格、開高低收範圍錯誤、無效成交量或金額、未知單位與來源錯誤會阻擋儲存及正常指標顯示。
- 零成交量與資料過期會提醒。網路錯誤採有限次重試；來源狀態或格式異常直接顯示失敗，保留舊資料。
- 這是每日行情，不是即時報價；發布時間與可用性以官方來源為準。

正式流程不載入測試資料、不插值、不製造行情。不含轉折結構、支撐壓力、證據矩陣、市場階段、AI 解說或交易訊號。
